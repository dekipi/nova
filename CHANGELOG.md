# Dekipi Nova Code Changelog

## 0.0.3

- Fixed issue that providing the context using the ACP compatible client will
  return error
- Added support to delete threads
- Fixed issue that threads list doesn't scroll properly
- Added working directory to the threads list
- Fixed issue that Nova messages is not listed in the threads viewer
- Added support for the Model Context Protocol
- Added subcommands hints to the commands
- Added support for opening links from terminal
- Resuming ACP session is now supported

## 0.0.2

- Added support for the Agent Client Protocol (ACP)
  on how to add it to your editor.
- Fixed issue that scrollbar may have wrong alignment
- Number of changed lines is now rendered when file is edited
- Support to disable auto updates with `auto_update: false` config option
- Fixed issue that using "Ctrl+C" on active chat will close the app

## 0.0.1

- Initial release of Nova Code CLI
